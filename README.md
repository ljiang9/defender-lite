# defender-lite

极简 Defender 克隆:横向卷轴太空射击。驾驶飞船巡逻,击落登陆者(Lander),
阻止它们抓走地面平民。

## 玩法

- `L`:登陆者,会下降抓取地面平民 `H`
- 被抓住的平民会被带上天(`U`);到顶则平民丢失
- 开火击落抓人的 Lander,平民会坠落(`h`)——接住它得 500 分并救援,掉地上则死亡
- 智能炸弹 `b`:清屏(3 枚)
- 撞上 Lander 失去一条命(共 3 条);平民全部丢失则游戏结束

## 运行

```bash
python3 defender_lite.py            # 交互模式
python3 -m defender_lite            # 同上
python3 defender_lite.py --auto --frames 600 --seed 7   # 无头自动演示
```

交互操作(每行一个命令,回车执行):

| 按键 | 动作 |
| ---- | ---- |
| a / d | 左 / 右 |
| w / s | 上 / 下 |
| 空格 | 开火 |
| b | 智能炸弹 |
| q | 退出 |

## 自动演示示例

```
$ python3 defender_lite.py --auto --frames 600 --seed 2026
自动演示结束:得分 3000,击杀 10,救援 3,剩余平民 0/6,生命 2,帧数 425,平民全部丢失
```

## 已知局限

- 文本渲染,无实时输入:交互是回合制(每行命令推进一帧),手感不如街机
- 无音效、无变异体(mutant)等进阶敌人,机制是 Defender 的极简子集
- 自动演示的 AI 只做"保距离射击 / 优先救坠落平民 / 紧急拉开",走位简单,高难度下仍可能全灭
